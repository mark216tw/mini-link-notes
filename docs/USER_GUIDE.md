# 使用指南

本文件說明 mini網頁筆記的安裝、日常操作與常見問題。

## 1. 系統需求

- Android 8.0（API 26）以上
- 建議 Android 12 以上，以使用動態色彩
- 不需要註冊帳號，也不需要網路即可瀏覽已儲存的筆記
- 只有「自動取得網頁標題」需要網路

## 2. 安裝

### 2.1 安裝 GitHub 測試版

1. 開啟 [Releases](https://github.com/mark216tw/mini-link-notes/releases) 頁面。
2. 下載 `app-prerelease.apk`。
3. 在手機上點擊 APK，若系統提示不允許安裝未知來源，依指示允許該檔案管理器或瀏覽器安裝。
4. 安裝完成後開啟「mini網頁筆記」。

> `app-prerelease.apk` 使用 Android Debug 金鑰簽署，僅供測試。未來若改用正式金鑰簽署，可能需要先解除安裝測試版才能更新。

### 2.2 從原始碼建置

請見 [BUILD.md](BUILD.md)。

## 3. 第一次使用

開啟 App 後會看到空白清單。你可以：

- 點右下角「＋」手動新增筆記。
- 從瀏覽器或其他 App 分享內容進來。
- 到「更多 → 標籤管理」先建立常用標籤。

## 4. 新增筆記

### 4.1 從其他 App 分享

在瀏覽器、社群 App 或任何支援分享的 App 中：

1. 點「分享」。
2. 選擇「mini網頁筆記」。
3. App 會自動儲存分享的網址或文字，並顯示「已儲存筆記」。
4. 若想立刻補充內容，點 Snackbar 上的「編輯」。

支援的分享格式：

- `text/plain`：純文字，內含網址時會自動辨識為連結筆記。
- `text/html`：HTML 內容，會取出第一個連結與純文字內容。

### 4.2 選取文字後儲存

在支援文字選取選單的 App 中選取文字，點選單中的「mini網頁筆記」，即可直接存成文字筆記。實際選單位置依 App 與系統版本而異。

### 4.3 手動新增

1. 點右下角「＋」。
2. 選擇類型：
   - **連結**：需要有效的 `http` 或 `https` 網址，內容為選填。
   - **文字**：內容必填，標題可留空，系統會取第一行作為標題。
3. 可選擇標籤。
4. 點右上角「儲存」。

新增連結時，若標題留空且開啟「自動取得網頁標題」，App 會在背景連線讀取網頁標題。

## 5. 瀏覽與閱讀

- **點擊卡片**：連結筆記會用系統瀏覽器開啟；文字筆記會進入編輯畫面。
- **左側圓圈**：切換已讀／未讀。未讀標題會以較粗字體顯示。
- **標題列**：顯示筆記總數與未讀數；有篩選時改顯示結果數。
- **更多選單**：全部已讀、標籤管理、設定。
- **卡片右側「⋮」**：編輯、開啟連結、複製網址／內容、分享、刪除。

## 6. 搜尋、篩選與排序

### 6.1 搜尋

在搜尋框輸入關鍵字，會比對標題、網址與內容。輸入時清單即時更新，背景過濾有 200 毫秒延遲，避免大量筆記時卡頓。

### 6.2 篩選

- 點「全部」清除標籤與未讀篩選。
- 點「未讀 N」只看未讀筆記。
- 點標籤 chip 可多選標籤，筆記需符合其中任一所選標籤。
- 點筆記卡片上的標籤，也會切換該標籤篩選。

### 6.3 排序

點搜尋框右側的排序圖示，可選擇：

- 加入時間（新→舊）
- 加入時間（舊→新）
- 標題（A→Z）
- 標題（Z→A）
- 標籤順序

目前排序方式會以勾選圖示標示。

## 7. 標籤管理

從「更多 → 標籤管理」進入。

- **新增**：點右下角「＋」，輸入名稱並選擇 12 色之一。
- **改名／改色**：點標籤右側「⋮ → 編輯」。
- **排序**：長按左側握把拖曳，或使用「⋮ → 上移／下移」。
- **刪除**：點「⋮ → 刪除」。刪除標籤不會刪除筆記，只會移除關聯；系統會先顯示受影響的筆記數量。

標籤名稱不可重複（忽略大小寫）。

## 8. 回收筒

- 刪除筆記後會先移到回收筒，並顯示可復原的 Snackbar。
- 回收筒保留 30 天，畫面會顯示剩餘天數。
- 可個別「復原」或「永久刪除」。
- 右上角可「清空回收桶」，執行前會二次確認。
- 匯出備份不包含回收筒中的筆記。

## 9. 設定

### 外觀

- **顯示模式**：跟隨系統、淺色、深色。
- **動態色彩**：Android 12 以上可跟隨桌布配色。

### 行為

- **自動取得網頁標題**：新增或分享連結時連線到網頁讀取標題。關閉後可手動按「重新取得標題」。

### 資料

- **匯出 JSON**：匯出所有未刪除的筆記與標籤。
- **匯入 JSON**：
  - **合併匯入**：保留現有資料，略過重複的網址或文字內容。
  - **覆蓋匯入**：先清空所有筆記與標籤，再匯入備份；執行前會二次確認。

### 關於

顯示版本、Build Type、隱私說明與開源元件。

## 10. 備份與還原

建議定期從「設定 → 匯出 JSON」備份。備份檔包含：

- 標籤名稱、顏色索引、排序
- 筆記類型、標題、網址、內容、已讀狀態、建立與更新時間、標籤關聯

注意事項：

- 備份檔不含回收筒內容。
- 匯入不會還原「已刪除」狀態。
- 合併匯入時，連結以正規化後的網址比對，文字筆記以完整內容比對。
- 若備份檔的 `schemaVersion` 高於 App 支援版本，會提示先更新 App。

備份格式範例請見 [ARCHITECTURE.md](ARCHITECTURE.md#8-json-備份格式)。

## 11. 常見問題

### 為什麼網頁標題沒有自動出現？

可能原因：

- 「自動取得網頁標題」已關閉。
- 網頁需要登入、阻擋爬蟲，或內容由 JavaScript 動態產生。
- 網路逾時（連線 8 秒、讀取 8 秒、整體 12 秒）。

可在編輯畫面按「重新取得標題」，或手動輸入標題。

### 為什麼已讀狀態沒有自動改變？

已讀／未讀完全由使用者手動切換。開啟連結不會自動標為已讀。

### 分享後沒有看到筆記？

- 確認分享的內容不是空白。
- 若分享的是連結且已存在相同網址，仍會儲存，但會提示「已有相同連結」。
- 可回首頁下拉或重新開啟 App 確認。

### 為什麼安裝更新時失敗？

測試版使用 Android Debug 金鑰簽署。若之前安裝的是不同簽章版本，需先解除安裝舊版；解除安裝會清除本機資料，請先匯出 JSON 備份。

### 資料會不會上傳？

不會。筆記只存在本機。只有在開啟「自動取得網頁標題」時，App 會連線到你儲存的網址讀取 HTML 標題。詳見 [PRIVACY.md](PRIVACY.md)。

## 12. 解除安裝與資料刪除

解除安裝 App 會刪除本機資料庫與設定。若系統備份曾備份此 App，資料可能保留在 Android 備份機制中，可在系統設定中清除。你也可以在 App 內先刪除筆記、清空回收桶，再解除安裝。

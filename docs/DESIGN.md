# 系統設計文件

本文件描述 mini網頁筆記的產品目標、資訊架構、畫面設計、狀態模型與關鍵設計決策。

## 1. 設計目標

1. **收集要快**：從任何 App 分享內容，不需切換 App 或登入。
2. **整理要簡單**：用標籤、搜尋、未讀狀態維持可管理的閱讀清單。
3. **資料要安全**：預設本機儲存，不強制網路或帳號。
4. **操作要可逆**：刪除可復原，覆蓋匯入需二次確認。
5. **介面要一致**：Material 3、淺色／深色、Edge-to-edge。

## 2. 範圍

### 包含

- 分享與手動新增連結／文字筆記
- 標題自動抓取
- 已讀狀態
- 多標籤與排序
- 搜尋與篩選
- 軟刪除與回收筒
- JSON 備份與還原
- 主題與動態色彩

### 不包含

- 帳號、登入、雲端同步
- 跨裝置即時同步
- 全文搜尋索引（FTS）
- 網頁內容全文擷取或離線閱讀
- 圖片、附件
- 分享至其他 App 的完整內容改寫

## 3. 使用者與情境

| 情境 | 使用者動作 | 系統回應 |
| --- | --- | --- |
| 看到想讀的文章 | 在瀏覽器分享到 App | 儲存連結、抓標題、提示可編輯 |
| 看到一段文字 | 選取文字 → 系統選單 | 儲存文字筆記 |
| 想分類 | 建立標籤、加標籤 | 標籤 chip 顯示顏色與名稱 |
| 想找舊筆記 | 搜尋或點標籤 | 即時過濾清單 |
| 讀完文章 | 點圓圈標為已讀 | 標題恢復一般字重 |
| 誤刪 | 點 Snackbar「復原」 | 筆記回到清單 |
| 換手機 | 匯出 JSON → 新機匯入 | 還原筆記與標籤 |

## 4. 資訊架構

```
首頁（筆記清單）
├── 搜尋列
├── 篩選列（全部 / 未讀 / 標籤）
├── 排序選單
├── 筆記卡片
└── 更多
    ├── 全部已讀
    ├── 標籤管理
    └── 設定
        ├── 外觀
        ├── 行為
        ├── 資料（匯出／匯入）
        └── 關於

編輯頁
├── 類型（連結／文字）
├── 標題
├── 網址（連結）
├── 重新取得標題（連結）
├── 內容
├── 標籤
└── 儲存

回收筒
├── 筆記卡片（剩餘天數）
├── 復原
├── 永久刪除
└── 清空回收桶
```

## 5. 畫面設計

### 5.1 首頁

- **TopAppBar**：標題「網頁筆記」＋副標題（總數／未讀／結果數）；右側回收筒與更多選單。
- **搜尋列**：左側搜尋圖示、右側清除按鈕；IME 動作為「搜尋」。
- **排序**：搜尋列右側圖示，選單以勾選與主色標示目前選項。
- **篩選列**：水平捲動 chips；「全部」在無篩選時選中；「未讀 N」顯示未讀數。
- **清單**：`LazyColumn`，卡片間距 8dp，底部留 96dp 避免 FAB 遮擋。
- **卡片**：
  - 左側已讀切換（`CheckCircle`／`RadioButtonUnchecked`）
  - 標題（未讀為 SemiBold，最多 2 行）
  - 連結顯示網域
  - 內容摘要（連結 2 行、文字 3 行）
  - 最多 4 個標籤 pill，其餘顯示 `+N`
  - 相對時間
  - 右側「⋮」選單
- **空狀態**：無筆記時顯示引導與新增按鈕；有篩選但無結果時顯示清除篩選。
- **FAB**：右下角「＋」新增。

### 5.2 編輯頁

- 類型以 `FilterChip` 切換；切換不自動清除已輸入內容。
- 連結類型顯示網址欄與「重新取得標題」；文字類型隱藏網址欄。
- 使用者手動改標題後顯示「已手動編輯標題，不會自動覆寫」。
- 儲存失敗區分：
  - 網址格式錯誤：「請輸入有效的 http 或 https 網址」
  - 文字內容空白：「請輸入文字內容」
  - 其他：「儲存失敗，請稍後再試」
- 有未儲存變更時按返回會跳出「放棄未儲存的變更？」。

### 5.3 標籤管理

- 清單列：拖曳握把、顏色圓點、名稱、筆記數、更多選單。
- 新增／編輯 Dialog：名稱欄＋12 色圓形色票，選中色票加 3dp 主色外框。
- 刪除前顯示受影響的筆記數量，明確說明只移除關聯、不刪筆記。
- 支援長按拖曳與上／下移兩種排序方式。

### 5.4 回收筒

- 卡片顯示標題、網域、內容摘要、刪除時間、剩餘天數。
- 剩餘 ≤ 3 天以錯誤色顯示。
- 操作：開啟連結（連結筆記）、復原、永久刪除。
- 清空回收桶需二次確認。

### 5.5 設定與關於

- 設定分區：外觀、行為、資料、關於。
- 顯示模式以 chips 呈現；動態色彩在 Android 12 以下停用。
- 匯入流程：選檔 → 選擇合併／覆蓋 → 覆蓋再確認。
- 關於頁顯示版本、Build Type、隱私說明與開源元件。

## 6. 狀態模型

`NotesUiState` 是 UI 的唯一狀態來源：

```kotlin
data class NotesUiState(
    val isLoading: Boolean,
    val settings: AppSettings,
    val notes: List<NoteWithTags>,        // 已篩選、已排序
    val tags: List<TagEntity>,
    val tagsWithCount: List<TagWithNoteCount>,
    val trash: List<NoteWithTags>,
    val query: String,                     // 即時輸入值
    val selectedTagIds: Set<Long>,
    val unreadOnly: Boolean,
    val unreadCount: Int,                  // 全部未讀，不受篩選影響
    val totalCount: Int,                   // 全部筆記
)
```

設計要點：

- `query` 保持即時，讓 `TextField` 不延遲；`filterQuery` 才 debounce。
- `selectedTagIds` 會與現有標籤取交集，避免刪除標籤後留下無效篩選。
- `unreadCount` 使用篩選前的資料，讓使用者知道整體未讀量。
- UI 不保存業務狀態，只有區域 UI 狀態（選單展開、Dialog）。

## 7. 關鍵流程設計

### 7.1 分享內容解析

```
純文字 → 正規化 → 擷取第一個 http(s) URL
        ├── 有 URL：LINK，文字作為 content（若與 URL 相同則省略）
        └── 無 URL：TEXT
HTML   → Jsoup → 第一個 <a href> 或文字中的 URL
        → body 純文字、document title
```

- 網址補上 `https://`、拒絕非 http(s)、拒絕含帳號密碼的 URL。
- 結尾標點（句號、逗號、括號等）會去除，避免把中文標點納入網址。

### 7.2 重複連結處理

- 新增時在 Room 交易中比對未刪除筆記的 URL。
- 使用 `dedupeKey`：小寫 scheme/host、去除預設埠、去除結尾斜線。
- 重複仍會儲存，但提示「已儲存筆記，但已有相同連結」，不強制封鎖使用者。

### 7.3 已讀狀態

- 只有使用者點圓圈或「全部已讀」才會改變。
- 開啟連結不自動標已讀，避免使用者失去閱讀追蹤。
- 切換使用單一 SQL `UPDATE ... SET isRead = NOT isRead`，避免讀改寫競態。

### 7.4 刪除與復原

- 軟刪除保留 30 天，符合「誤刪可救」與「資料不會無限膨脹」的平衡。
- 復原後筆記回到原建立時間排序位置。
- 永久刪除與清空回收桶皆需確認。

### 7.5 匯入策略

| 模式 | 適用情境 | 行為 |
| --- | --- | --- |
| 合併 | 從其他裝置補充資料 | 保留現有，略過重複 URL／文字 |
| 覆蓋 | 完整還原 | 清空後匯入，需二次確認 |

匯入在單一交易中完成，失敗不會留下半套資料。

## 8. 視覺設計

- **色彩**：品牌主色深青 `#0F766E`；深色模式使用 `#7ED9CE`。
- **動態色彩**：Android 12+ 且使用者開啟時，改用系統產生的 light/dark scheme。
- **標籤色**：12 色，每色提供淺色與深色兩版，確保對比。
- **圓角**：卡片、欄位、Dialog 主要使用 12dp。
- **間距**：以 4dp 為基準；畫面邊距 16dp，清單間距 8dp。
- **字體**：Material 3 Typography，不逐處指定 `fontSize`。
- **圖示**：Material Icons Outlined，維持一致線條風格。

## 9. 回饋與錯誤處理

- 所有成功操作以 Snackbar 提示；有後續動作（編輯、復原）時延長顯示。
- Snackbar 顏色使用 `surfaceVariant`／`onSurfaceVariant`／`primary`，跟隨主題。
- 破壞性操作（永久刪除、清空回收桶、覆蓋匯入、刪除標籤）皆有確認 Dialog。
- 空狀態、載入中、錯誤狀態皆有對應畫面或文字。
- 網路失敗不阻塞儲存；標題抓取失敗只影響標題。

## 10. 無障礙與國際化

- 可點擊圖示皆提供 `contentDescription`。
- 色票以「顏色 N」描述並標示選中狀態。
- 支援 RTL（`supportsRtl=true`）。
- 文案集中於 `res/values/strings.xml`，預設繁體中文。
- 標籤名稱、筆記內容支援使用者輸入的任意語言。

## 11. 設計決策與取捨

| 決策 | 理由 | 取捨 |
| --- | --- | --- |
| 本機優先、無帳號 | 降低使用門檻與隱私風險 | 無跨裝置同步 |
| 手動已讀 | 尊重使用者閱讀節奏 | 需多一步操作 |
| 重複連結仍可儲存 | 不同來源可能有不同脈絡 | 清單可能出現相似項目 |
| 軟刪除 30 天 | 可復原、避免資料無限成長 | 回收筒仍需使用者管理 |
| 記憶體搜尋 | 實作簡單、即時 | 大量資料時效能受限 |
| 手動 DI | 依賴少、啟動快 | 大型專案需改用 DI 框架 |
| 備份用 JSON | 可讀、可移植、易除錯 | 檔案較大、無加密 |

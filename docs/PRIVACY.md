# 隱私權說明

本文件說明 mini網頁筆記（以下稱「本 App」）如何處理資料。最後更新：2026-10-30。

## 1. 摘要

- 本 App 不需要註冊帳號。
- 筆記與設定預設只儲存在你的裝置。
- 本 App 沒有廣告、沒有分析追蹤、沒有雲端同步。
- 唯一的網路行為是：當你開啟「自動取得網頁標題」時，連線到你新增或分享的網址讀取 HTML 標題。

## 2. 收集的資料

本 App 不主動收集個人識別資料，也不將資料傳送給開發者。

你自行輸入或分享的內容會儲存在裝置本機：

| 資料 | 儲存位置 | 用途 |
| --- | --- | --- |
| 筆記標題、網址、內容 | Room 資料庫 | 顯示與管理筆記 |
| 已讀狀態、建立／更新時間 | Room 資料庫 | 閱讀追蹤與排序 |
| 標籤名稱、顏色、排序 | Room 資料庫 | 分類與篩選 |
| 顯示模式、動態色彩、自動抓標題、排序 | DataStore | 記住設定 |

## 3. 權限

本 App 只宣告以下權限：

| 權限 | 用途 |
| --- | --- |
| `INTERNET` | 在「自動取得網頁標題」開啟時，連線讀取你儲存的網址標題 |

本 App 不要求存取聯絡人、位置、相機、麥克風、通訊錄或檔案系統的廣泛權限。備份匯入／匯出使用 Android 系統檔案選擇器，只會取得你明確選擇的檔案。

## 4. 網路連線

當你新增或分享連結，且「自動取得網頁標題」開啟時：

1. 本 App 使用 OkHttp 向該網址發出 HTTP GET。
2. 請求帶有一般瀏覽器 User-Agent 與 `Accept-Language`。
3. 回應限制在 1 MiB 以內，連線／讀取逾時各 8 秒，總逾時 12 秒。
4. 本 App 只解析 `<title>` 或 `og:title`，不儲存整份網頁。

該網站的伺服器可能會記錄你的 IP、請求時間與 User-Agent，這屬於該網站自己的隱私政策範圍。若你不希望連線，請在設定中關閉「自動取得網頁標題」。

本 App 不會將筆記內容傳送給開發者或第三方。

## 5. 系統備份

本 App 的 Android Manifest 開啟 `allowBackup="true"`，並提供備份規則。若你的裝置開啟 Google 或裝置廠商的系統備份，Android 可能將 App 資料備份到你的雲端帳戶。此行為由 Android 系統與你的帳號設定控制，不由本 App 直接上傳。

你可以在 Android 系統設定中關閉 App 備份，或清除已備份的資料。

## 6. 備份檔案

- 匯出 JSON 時，檔案會寫入你透過系統檔案選擇器指定的位置。
- 檔案包含筆記與標籤，不含回收筒內容。
- 備份檔未加密，請妥善保管；若包含敏感內容，建議存放在受保護的位置。

## 7. 資料刪除

- 刪除筆記會先移到回收筒，30 天後自動永久刪除。
- 你可以隨時在回收筒中永久刪除或清空。
- 解除安裝 App 會刪除本機資料庫與設定。
- 系統備份中的資料可能仍存在，需透過 Android 系統設定清除。

## 8. 兒童隱私

本 App 不針對兒童設計，也不主動收集兒童個人資料。

## 9. 第三方元件

本 App 使用多個開源元件，例如 Jetpack Compose、Room、DataStore、OkHttp、Jsoup、Kotlin Serialization。這些元件在本機執行，不會自行收集或傳送資料。其授權與隱私實作請參考各專案官方說明。

## 10. 變更

若本說明有重大變更，會更新本文件並記錄於 `CHANGELOG.md`。建議定期查看最新版本。
